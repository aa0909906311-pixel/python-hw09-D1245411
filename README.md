## 1. 程式用途與執行方式

本程式運用 Python 的字串處理（`.replace()`、`.lower()`、`.split()`）與四大基礎容器（`tuple`、`list`、`set`、`dict`），整理「桌遊體驗」與「電影欣賞」兩場活動的原始報名名單。程式先保留原始順序建立串列，再透過集合（`set`）去除同一場的重複報名並計算交集、聯集與雙向差集，最後以字典（`dict`）統整各場去重人數、報名人次與應收費用。

## 3. 作業問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
* **為什麼以 3 人計算**：整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']`，其中 `'amy'` 因為大小寫不同（原本是 `" Amy"` 與 `"amy"`）重複報名了兩次。依活動規則，同一個人在同一場活動重複出現只算一位參加者、只收一次該場費用，因此實際只有 3 位不同的人參加，桌遊費用應以 `3 × 120 = 360` 元計算。
* **拆成 `list` 與轉成 `set` 的差異**：
  * **直接拆成 `list`**：**保留了**原始報名的先後順序與重複出現的次數，方便追蹤原始報名紀錄；但**失去了**自動排除重複項目的能力，也無法直接做交集、差集等集合比較。
  * **再轉成 `set`**：**保留了**不重複的唯一參加者名單，並獲得交集、聯集、差集等集合運算功能；但因為集合是無序的，所以**失去了**原本的報名先後順序以及重複報名的次數紀錄（因此顯示時需要再用 `sorted()` 重新排序）。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
* **集合關係說明**：在測試三中，桌遊集合 `board_set` 為 `{'amy', 'ben', 'cora'}`（3 人），電影集合 `movie_set` 也是 `{'amy', 'ben', 'cora'}`（3 人）。兩者的**聯集**（`board_set | movie_set`）與**交集**（`board_set & movie_set`）完全相同，都是這 3 個人，所以「總不重複人數」為 `len(all_set) = 3` 人，且兩個方向的差集（只參加單一場次者）皆為空集合 `[]`。
* **人次與費用算式**：因為規則規定「同一人參加兩場活動，兩場費用分別計算」，這 3 個人都同時參加了兩場活動，因此報名人次為兩場去重人數相加：`3 + 3 = 6` 人次。費用計算如下：
  * 桌遊應收：`3 人 × 120 元 = 360.00 元`
  * 電影應收：`3 人 × 80 元 = 240.00 元`
  * 總應收：`360.00 + 240.00 = 600.00 元`
